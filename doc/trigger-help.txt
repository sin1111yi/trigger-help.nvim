*trigger-help.txt*  事件触发帮助浮动窗口（md / :h 内容）

==============================================================================
INTRODUCTION                                    *trigger-help*

事件触发帮助浮动窗口插件。按下 / ? : 等按键（或任意可配置事件）时在屏幕
右上角弹出对应帮助内容。内容来自 markdown 文件或内置 :h 文档，插件不内置
任何内容。零依赖、单文件、setup() 全参数可配。

安装：放到 pack/*/opt/trigger-help.nvim/，packadd 后调用 setup()。

==============================================================================
SETUP                                              *trigger-help-setup*

    vim.cmd('packadd trigger-help.nvim')
    require('trigger_help').setup({
      content = {
        ['/'] = '~/.config/nvim/keyhelp/search.md',   " md 文件路径
        ['?'] = { help = 'search' },                  " 内置 :h 文档形态
        [':'] = '~/.config/nvim/keyhelp/cmd.md',
      },
      trigger = 'CmdlineEnter',    " 或 { event='BufEnter', pattern='*.lua' }
      close = 'CmdlineLeave',      " 或数组（多个关闭事件）
      match = function() return vim.fn.getcmdtype() end,  " 返回 content 键
      width = 44,
      pos = 'top-right',           " top-right|top-left|bottom-right|bottom-left|center
      border = 'rounded',
      zindex = 50,
      margin = 1,
    })

配置项：~

content  内容表：键 → md 文件路径（string）或 { help = '<tag>' }。
         空表/未设 = 零行为（不注册任何 autocmd）。
trigger  触发事件。string 或 { event = ..., pattern = ... }。
close    关闭事件。string 或数组，任一触发即幂等关闭。
match    触发后调用，返回 content 键；nil/'' 不显示。
         默认：trigger 含 CmdlineEnter 时自动用 getcmdtype()，
         其他事件无默认（不显示）。
width    浮动窗口宽度，全局统一。
pos      位置枚举（见 *trigger-help-pos*）。
border   边框（'rounded' 等）。
zindex   窗口层级，默认 50，高于普通浮动窗口。
margin   窗口与屏幕边缘间距，默认 1。

==============================================================================
BEHAVIOR                                            *trigger-help-behavior*

md 渲染（极简）：行首 #/## 整行 Title 高亮；行首 - 替换为 2 空格缩进；
其余原样，不解析行内 md。

:h 形态：静默执行 :help <tag>（pcall 包裹）→ 读取该 tag 所在小节 → 关闭
help 窗口 → 渲染到浮动窗口，保留 filetype='help' 获得内置高亮。

异常路径：
- md 文件缺失：vim.notify WARN 一次（每路径每会话），不显示不崩溃。
- match 返回键不在 content：静默。
- 同一时刻只保留一个浮动窗口；关闭幂等，重复触发不报错。
- setup() 幂等：vim.g.trigger_help_loaded 守卫，重复调用不重复注册
  （opt 插件双 source 场景）。

==============================================================================
POSITIONS                                           *trigger-help-pos*

top-right / top-left / bottom-right / bottom-left / center
基于编辑器区域（relative='editor'），margin 控制与边缘间距。
